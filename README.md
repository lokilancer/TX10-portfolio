# TX10 Fastest Line Follower Portfolio

Bilingual English/Tamil portfolio for the Sri Lankan student team preparing for TechnoXian World Cup 10.0.

## GitHub Pages
The site is deployed from the repository root using the GitHub Actions workflow in `.github/workflows/pages.yml`.

Expected URL: https://lokilancer.github.io/TX10-portfolio/

## Important notes
- This is a static website; no server is required.
- Content edits and media uploads made through the website are stored in that visitor's browser local storage. They are not shared with other visitors.
- Replace placeholder robot specifications and testing data with verified project information before presenting them as final results.
