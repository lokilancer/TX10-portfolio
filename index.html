THE ENGINEERING

Technology

Sensing, embedded programming and feedback control working as one system.

👁️

Line Sensing

Infrared sensors detect the position of the track and provide real-time feedback.

🧠

PID Control

PID converts line-position error into steering correction for smoother tracking.

⚡

Motor Control

The controller adjusts left and right wheel speed through the motor driver.

🔧

Calibration

Sensor thresholds and PID parameters are tuned through practical testing.

THE JOURNEY

Build Journey

From first idea to competition-ready robot.

01 — Concept

Research the competition, track requirements and robot architecture.

02 — Prototype

Build the chassis, connect sensors and motors, and establish basic line following.

03 — Control

Implement and tune PID control for stable tracking.

04 — Testing

Run repeated tests on straight lines, corners and curves.

05 — Optimization

Improve traction, speed, weight distribution and software.

06 — Competition

Final inspection, practice and preparation for TechnoXian World Cup 10.0.
